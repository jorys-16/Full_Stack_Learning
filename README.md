# 🗺️ Full Stack AI Engineer Master Roadmap

This interactive syllabus integrates four key learning resources into a single, phased execution plan.

## 📚 Core Resources
1. [The Odin Project: Full Stack JavaScript](https://www.theodinproject.com/paths/full-stack-javascript)
2. [Codecademy: Machine Learning/AI Engineer](https://www.codecademy.com/learn/paths/machine-learning-engineer)
3. [TTP Summer 2026 Cohort Repo](https://github.com/aghaffar570/ttp-summer-2026)
4. [Coursera AI & Cloud Modules](https://www.coursera.org/my-learning)

## 🏗️ Phase 1: Web Foundation (PERN Stack)
*Combining TTP Summer 2026 & The Odin Project.*

- [ ] **HTML, CSS, & Git Fundamentals**
  - [ ] TTP Week 1: Dev Environment + HTML/CSS/JS/Git (Solo)
  - [ ] TTP Week 2: HTML & JS/Git (Collaborative) & DOM Manipulation
  - [ ] Odin: Intermediate HTML and CSS
- [ ] **JavaScript & UI Architecture (React)**
  - [ ] Odin: JavaScript (Object-Oriented, APIs)
  - [ ] TTP Week 3: React I & II, API Requests
  - [ ] Odin: React
- [ ] **Backend Engineering (Node.js & Express)**
  - [ ] TTP Week 4: Server (Express.js), Middleware & Routing
  - [ ] Odin: NodeJS (Server-side JavaScript)
- [ ] **Database Management (PostgreSQL)**
  - [ ] Odin: Databases (Relational DBs, SQL)
  - [ ] TTP Week 5: Database (PostgreSQL & Sequelize)
- [ ] **Deployment & Security**
  - [ ] TTP Week 6 & 7: Client-Side Routing, Auth0, Deployment (Vercel, Render, Neon)
